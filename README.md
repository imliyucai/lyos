

这个项目是我基于 lyos 程序框架的一个实际项目。lyos 是我琢磨出来的程序框架。
传统的程序框架是一个大循环，需要做的事务依次执行，执行完一次循环再下一次循环。
在这种架构里，延时执行非常难办。
